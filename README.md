# Aura-Meteo
Dynamic weather intelligence platform with real-time forecasts, radar, AQI, analytics and alerts.


## ✨ Features
- 🌡️ Real-time weather conditions
- 📅 7-day weather forecast
- 🕐 24-hour weather forecast
- 🗺️ Interactive weather radar map
- 🌧️ Precipitation visualization
- 💨 Wind and atmospheric information
- 🌬️ Air Quality Index (AQI)
- 🧪 Detailed pollutant information
- 🚨 Dynamic weather alerts
- 📊 Weather analytics and charts
- ❤️ Saved / favorite cities
- ☀️ Sunrise and sunset information
- 🌙 Lunar information
- 📍 Geolocation support
- 🔍 City search
- 🌗 Dark and light themes
- 🎨 Custom accent colors
- 🌡️ Celsius / Fahrenheit conversion
- 💾 Local storage preferences
- 🔐 Startup loading and login interface

 ## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Leaflet.js
- Lucide Icons
- LocalStorage

## 🌐 APIs & Libraries

### Open-Meteo
Used for weather forecasts, current conditions, hourly forecasts, daily forecasts, atmospheric data and air-quality information.

### Leaflet.js
Used to create the interactive weather map interface.

### Lucide
Used for the application's modern interface icons.

## 🎯 Project Objective

AURA METEO was developed to go beyond a basic weather application by combining multiple weather-related data sources and presenting them through an interactive dashboard.

The project focuses on API integration, dynamic data rendering, interactive maps, client-side state management, responsive UI design, local storage, and user-focused dashboard development.
